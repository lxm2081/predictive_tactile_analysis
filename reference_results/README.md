# Reference result tables

These CSV files contain the numerical reference results associated with the reported analysis. They are used only after the full analysis has been rerun, to check whether the regenerated result tables agree within the tolerance in `config/reproduce_v3.json`. They are not read during model fitting, score calculation, threshold selection or event evaluation.

To regenerate the results, download the measured data from https://doi.org/10.5281/zenodo.23420547 and follow the instructions in the root `README.md`.
